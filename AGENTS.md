# Agent instructions

## Session startup

1. Read `PROJECT_STATE.md`.
2. Read the active Linear issue.
3. Follow links to relevant specifications, decisions, research, and evaluations.
4. Inspect the current branch and relevant recent changes.
5. Do not reopen accepted decisions without new evidence.

## During work

- Keep work within the active task scope.
- Record consequential decisions and evaluation evidence.
- Add newly discovered out-of-scope work to Linear Inbox with the `agent-found` label.
- Do not silently expand a task.
- Do not mark work complete without relevant verification.

## Session completion

- Update durable documentation when actual project state changed.
- Update the Linear issue with evidence.
- Create a handoff for unfinished work.
- Report checks, failures, risks, and the exact next action.

# Agent instructions

## Session startup

1. Start from the active Anklav task.
2. Load its Anklav context pack.
3. Read `PROJECT_STATE.md` and other Git-backed canonical artifacts.
4. Follow links to relevant specifications, decisions, research, and evaluations.
5. Inspect the current branch and relevant recent changes.
6. Never treat retrieved session text as canonical without verification.

## During work

- Keep work within the active task scope.
- Record consequential decisions and evaluation evidence.
- Add newly discovered out-of-scope work to Anklav Inbox.
- Use the Anklav task identifier in branches, commits, and pull requests.
- Do not silently expand a task.
- Do not mark work complete without relevant verification.

## Session completion

- Update durable documentation when actual project state changed.
- Send progress, evidence, and unfinished-work handoffs to Anklav.
- Create a Git-backed handoff for unfinished work.
- Report checks, failures, risks, and the exact next action.
